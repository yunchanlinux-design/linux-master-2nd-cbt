# 리눅스마스터 2급 CBT 학습 플랫폼

단일 HTML 파일로 실행하는 리눅스마스터 2급 학습용 CBT입니다. GitHub Pages에서 제공하며 별도 서버나 빌드 도구가 필요하지 않습니다.

## 현재 문제 데이터

- **내장 문항 합계: 86개**
- 기존 자체 제작 연습문제: 37개
- 신규 추가 문항: 49개. ComcBT의 공개 자료와 확인 가능한 출제 주제·시험 범위를 참고해 질문, 보기, 정답, 해설을 독립적으로 새로 작성했습니다.
- 실제 기출 원문을 그대로 복사해 내장한 문항: 0개
- 문제마다 출처 게시물 링크와 참고 연도·회차를 표시합니다.

## 조사 범위와 기준

2026년 10월 확인 시 ComcBT 게시판 목록에서 확인되는 가장 최근 회차는 **2023년 12월 9일(4회)** 이었습니다. 따라서 최근 게시 연도를 기준으로 조사 범위를 2017~2023년의 7개년으로 잡았습니다.

ComcBT의 게시물별 접근성은 동일하지 않습니다. 특히 게시판에는 2021년 시험부터 기출문제 비공개 전환 및 복원 관련 공지가 있으며, 2022년 1회는 복원 중으로 표시됩니다. 그러므로 7개년의 모든 실제 문항·정답·해설이 공개되었거나 전부 대조 검토되었다고 주장하지 않습니다. 연도와 회차가 각 문항에 표시될 때는 **참고한 출처 게시물의 연도·회차 메타데이터**를 의미하며, 그 문항이 실제 시험문항과 1:1로 대응한다는 뜻은 아닙니다. 원문 접근을 확인하지 못한 게시물은 출처 목록 확인용으로만 사용했습니다.

## 문제 은행 JSON 가져오기/내보내기

`백업 / 복원` 메뉴에서 문제 은행 JSON을 가져오거나 내보낼 수 있습니다. 각 문항은 `id`, `cat`, `q`, `a`, `ans`, `exp` 필드를 사용하며, `source`, `sourceUrl`, `year`, `session`은 출처 표시를 위한 메타데이터입니다. 가져온 문제 은행은 현재 브라우저의 로컬 저장소에 저장되며 기존 풀이 기록이 초기화됩니다.

## 실행 및 기능

`index.html`을 최신 브라우저에서 열거나 GitHub Pages 사이트를 이용하세요. 풀이 기록은 브라우저 `localStorage`에 저장됩니다.

- 학습 모드와 모의고사
- 자동 채점 및 해설 확인
- 오답노트와 북마크
- 학습 통계 및 테마 변경
- JSON 백업·복원

## 출처 및 정확성 원칙

이 프로젝트는 기출 학습을 돕기 위한 개인 학습용 사이트입니다. 출처 링크는 원 게시물을 확인하는 데 사용하며, 출처 표기만으로 원문 재사용 권한이 생긴다고 간주하지 않습니다. 실제 시험문제 원문을 수록하려면 해당 자료의 이용 조건과 필요한 권한을 별도로 확인해야 합니다.
