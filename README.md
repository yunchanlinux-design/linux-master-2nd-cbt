# 리눅스마스터 2급 CBT 학습 플랫폼

단일 HTML 파일로 실행하는 리눅스마스터 2급 학습용 CBT입니다. 별도 서버나 빌드 도구 없이 `index.html`을 브라우저에서 열 수 있습니다.

## 현재 데이터 상태

- 내장 문항: 자체 제작 연습문제 15개
- ComcBT 기출문항: 0개 포함
- 복원문항: 0개 포함
- 조사 기준: ComcBT 게시판에서 확인되는 최신 연도인 2023년
- 목표 7개년 범위: 2017~2023년(포함)
- 실제 기출 문항을 앱에 내장한 수: 0개 (출처·재사용 권한 검증 전)
- 앱 내 자료실: 2017~2023년 연도별 ComcBT 원문 게시판 링크 제공
- 문제 은행 JSON 가져오기/내보내기: 재사용 권한이 확인된 문항 세트를 CBT에 불러오는 기능

2026년 10월 확인 기준, ComcBT 게시판 목록에서 확인되는 가장 최신 연도는 2023년입니다. 따라서 '최신으로 올라와 있는 기출 연도 기준 7개년'은 2017~2023년으로 정의합니다. 게시판에는 2021년 시험부터 기출문제 비공개 전환 및 복원 관련 공지가 있고, 2022년 1회는 목록에서 복원 중으로 표시됩니다. 이 범위는 조사 목표이며, 모든 연도·회차의 원문/정답/해설이 확보되었다는 뜻은 아닙니다. 실제 문항을 무단 복사하지 않으며, 출처와 재사용 권한을 확인한 데이터만 앱에 추가합니다. 공개 게시판: https://www.comcbt.com/xe/index.php?mid=r2

## 7개년 자료실\n\n앱의 `🗂️ 7개년 자료실` 메뉴에서 2017~2023년 범위의 ComcBT 게시판으로 이동할 수 있습니다. 연도별 회차 메모와 함께 원 출처 링크를 제공하며, 원문 문제를 앱에 복사하지 않습니다. 2017년 자료는 게시판 2페이지에서 확인하도록 연결했습니다. 회차별 공개 여부와 해설 제공 여부는 원 게시물에서 확인해야 합니다.\n\n## 문제 은행 가져오기\n\n`백업 / 복원` 메뉴에서 권한이 확인된 문제 은행 JSON을 가져올 수 있습니다. JSON은 `questions` 배열을 포함하며 각 문항은 `id`, `cat`, `q`, `a`, `ans`, `exp` 필드를 가져야 합니다. `source`, `year`, `session`은 선택 항목입니다. 가져온 문제 은행은 해당 브라우저의 로컬 저장소에 저장되며, 기존 풀이 기록은 초기화됩니다. 현재 저장소에 기본 내장된 것은 자체 제작 연습문제 15개이고, ComcBT의 실제 기출 원문은 포함하지 않습니다. KAIT는 문제의 소유권과 무단 이용 금지를 안내하므로, 이용 허가 또는 재사용 권한이 확인된 자료만 가져오세요.\n\n## 실행

`index.html`을 최신 브라우저에서 열어 사용합니다. 학습 기록은 브라우저 `localStorage`에 저장됩니다. 브라우저 데이터 삭제 시 기록이 사라질 수 있으므로 JSON 백업 기능을 이용하세요.

## 기능

- 학습 모드와 모의고사
- 답안 채점 및 해설 확인
- 오답노트와 북마크
- 학습 통계 및 타이머
- JSON 백업/복원
- 라이트/다크 테마 및 반응형 화면

## 출처 및 정확성

현재 포함된 문제는 기출문제로 표시하지 않는 자체 제작 연습문제입니다. 7개년 조사 범위는 2017~2023년이며, 앱에 연도별 원문 자료실 링크를 추가했습니다. 이 저장소에는 실제 기출문항을 아직 포함하지 않았습니다. 실제 기출 데이터는 시험 연도·회차, 원문 접근성, 정답·해설 확인 여부, 재사용 조건을 검증한 뒤 별도 표시합니다.
