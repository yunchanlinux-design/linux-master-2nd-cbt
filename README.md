# 리눅스마스터 2급 CBT 학습 플랫폼

단일 HTML 파일로 실행하는 리눅스마스터 2급 학습용 CBT입니다. 별도 서버나 빌드 도구 없이 `index.html`을 브라우저에서 열 수 있습니다.

## 현재 데이터 상태

- 내장 문항: 자체 제작 연습문제 15개
- ComcBT 기출문항: 0개 포함
- 복원문항: 0개 포함
- 기출 7개년 범위: 아직 검증·구축 중

ComcBT 게시판에는 2021년 이후 기출문제 비공개 전환 및 복원 관련 공지가 있습니다. 실제 기출 문항을 무단 복사하지 않으며, 출처와 재사용 권한을 확인한 데이터만 추가합니다. 공개 게시판 목록은 https://www.comcbt.com/xe/index.php?mid=r2 에서 확인할 수 있습니다.

## 실행

`index.html`을 최신 브라우저에서 열어 사용합니다. 학습 기록은 브라우저 `localStorage`에 저장됩니다. 브라우저 데이터 삭제 시 기록이 사라질 수 있으므로 JSON 백업 기능을 이용하세요.

## 기능

- 학습 모드와 모의고사
- 답안 채점 및 해설 확인
- 오답노트와 북마크
- 학습 통계 및 타이머
- JSON 백업/복원
- 라이트/다크 테마 및 반응형 화면

## 출처 및 정확성

현재 포함된 문제는 기출문제로 표시하지 않는 자체 제작 연습문제입니다. 실제 기출 데이터는 시험 연도·회차, 원문 접근성, 정답·해설 확인 여부, 재사용 조건을 검증한 뒤 별도 표시합니다.
